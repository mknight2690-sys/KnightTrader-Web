Integration contract

This page is static. It does not connect to the Windows bot. Another process, the telemetry bridge, reads the installed tracker and publishes snapshots. Muse only displays them.

Baseline

Desk record: $17.830418 at 5 Nov 2026 15:18:36 America/New_York. Canonical instant 2026-11-05T15:18:36-05:00. The live balance is whatever the tracker sends. The baseline is not shown as current equity while the feed is down.

Performance

Today, this week, this month, and total profit and return percent come from the bot's durable Modified Dietz tracker, including initial partial periods. Muse does not recompute them from the equity curve, from fills, or from equity minus the baseline. External deposits and withdrawals make those shortcuts wrong.

On the first session, production windows open at the baseline instant and stay partial until each calendar period rolls. The contract preview uses extra period figures only to exercise the layout. Do not copy those figures into the bridge.

Transport

  • Publish a full snapshot about every 400ms. The desk coalesces bursts to the same window and renders at most one frame per 400ms.
  • WebSocket text frames are the JSON snapshot. SSE uses event: snapshot.
  • Do not poll a REST account endpoint at 2Hz to feed this desk.
  • Money is a decimal string, not a binary float. 17.830418 must stay exact.
  • Set source.live true only for the real tracker. The reference fixture server refuses a live fixture.
  • No private keys, tokens, webhooks, cookies, passwords, or session fields anywhere in the payload. No order or cancel channel.

CORS

Allow one exact GitHub Pages origin. Do not send Access-Control-Allow-Origin: * and do not allow credentials. Methods GET and OPTIONS. Headers Content-Type only. Browsers will send Origin. Reject every other origin. Put the capability in the path, not a query string.

Public market

The browser may subscribe to the public Hyperliquid websocket for mids and the BTC asset context. That tape is labeled public. It is not the account, and the 24h mark change computed here is not the bot's BTC trend.
